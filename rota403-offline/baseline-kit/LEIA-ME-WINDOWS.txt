ROTA 403 OFFLINE — PACOTE DE ADAPTAÇÃO WINDOWS

ESTADO DESTA ENTREGA
- Código PHP do pacote v.11 copiado para app/.
- config/config.php adaptado para banco local e BASE_URL na raiz.
- Database.php adaptado para aceitar DB_PORT.
- Banco SQL fornecido incluído em database/rota403.sql.
- Collation MariaDB 11 específica convertida para utf8mb4_unicode_ci.
- Scripts de inicialização e configuração do banco incluídos.
- Projeto Inno Setup incluído em installer/Rota403.iss.

REQUISITOS DO WINDOWS
1. Windows 10/11 64 bits.
2. PHP 8.1+ NTS x64, com pdo_mysql, mbstring, openssl e fileinfo habilitados.
3. MariaDB Server 11.x x64, configurado para escutar em 127.0.0.1:3307.
4. Navegador Edge ou Chrome.

IMPORTANTE
Esta entrega NÃO contém os binários Windows do PHP/MariaDB e NÃO contém um .exe compilado.
O ambiente de execução disponível para esta construção é Linux e não possui Inno Setup/compilador Windows.
O .iss é o projeto-fonte do instalador; para gerar Rota403-Offline-Setup.exe, instale Inno Setup no Windows,
adicione os runtimes oficiais nas pastas runtime/php e runtime/mariadb e compile installer/Rota403.iss.

CONFIGURAR O BANCO
- Ajuste MariaDB para porta 3307 e inicie o serviço.
- Execute PowerShell como administrador:
  .\\windows\\configurar-banco.ps1 -MariaDbBin "C:\\caminho\\mariadb\\bin"
- O script solicita senha de root e cria usuário/banco locais e importa database/rota403.sql.
- Não reutilize senha de produção. Defina uma senha local forte.

INICIAR
Execute windows\\iniciar-rota403.bat.
O PHP inicia em 0.0.0.0:8080 e abre http://127.0.0.1:8080/login.php.
A porta 0.0.0.0 permite acesso de outros dispositivos na LAN; não exponha essa porta à internet.
Para uso somente local, troque 0.0.0.0 por 127.0.0.1 no windows/php-servidor.bat.

LIMITAÇÕES AINDA NÃO RESOLVIDAS
- Sincronização bidirecional com Hostinger NÃO foi implementada. O pacote atual não contém API remota,
  fila de eventos, UUIDs de sincronização, controle de idempotência ou resolução de conflitos.
- Não foi possível validar compatibilidade integral entre o SQL fornecido e todos os arquivos v.11.
- A interface ainda referencia Bootstrap, Bootstrap Icons, Google Fonts e html5-qrcode por CDN.
  Portanto, a interface completa e o leitor de câmera ainda podem depender de internet. Para offline real,
  essas bibliotecas devem ser baixadas e servidas localmente, e os caminhos atualizados.
- QZ Tray não foi configurado nesta versão; as rotas de assinatura foram desativadas porque a chave privada
  original não deve ser embutida/distribuída sem controle. Impressão deve ser testada/configurada à parte.
- A versão mobile PWA não está implementada neste pacote.
- Faça backup do banco antes de qualquer importação. O SQL contém dados e usuários do ambiente de origem.

SEGURANÇA
- O arquivo config/config.local.php contém senha do banco local e não deve ser publicado.
- Certificados/chaves privadas originais foram excluídos do pacote.
- Configure firewall para permitir a porta 8080 somente na rede privada, se for usar celular.
